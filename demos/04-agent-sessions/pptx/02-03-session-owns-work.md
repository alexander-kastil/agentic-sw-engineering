# The session, not the window, owns the work

## Content

- Start a task long enough to still be running **a minute from now**
- **Close the window** while the agent works
- Reopen it: the session is **still running**, carrying the turns that completed
- Open it in a **second window**: both views track **one** session

## Notes

Under a client-authoritative model closing the window would end the run. Here the host never stopped tracking it.
