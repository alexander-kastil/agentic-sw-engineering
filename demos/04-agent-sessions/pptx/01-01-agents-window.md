# The Agents window

## Content

- A **companion window** for agent sessions, kept out of the main editor layout
- A **selectable harness** per window: Copilot, Claude, or Codex
- **Remote execution** and **per-window overrides** for model, project, and host
- Open it with **Open in Agents**, `Chat: Open Agents window`, or `code --agents`

## Notes

Agentic work is no longer a single blocking conversation in the sidebar. Extensions opt in through extensions.supportAgentsWindow.
