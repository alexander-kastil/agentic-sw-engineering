# Agent sessions and the Agents window

## Content

- Copilot has moved from an in-editor assistant to an **agent-session model**
- The **Agents window** is the companion surface where that model lives
- Sessions run across projects, locally or on remote hosts, as **first-class, long-lived objects**

## Notes

Having put agents to work in Implementing Agentic Coding, the room now meets the infrastructure underneath those runs: the window, the host beneath it, remote sessions, and the mechanics of running many sessions safely.
