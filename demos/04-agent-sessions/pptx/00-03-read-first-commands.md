# Read-first slash commands

## Content

- `/chronicle`: query session history with `standup`, `search`, `reindex`
- `/troubleshoot`: analyze the session's own record to diagnose a stall or a failed tool call
- `/btw`: ask a side question without interrupting the running turn
- **Ctrl+R** opens the Sessions picker to jump between sessions

## Notes

None of these commands changes code on its own. That is why they are safe while a session is still running.
