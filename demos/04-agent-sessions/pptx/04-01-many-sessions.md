# Layout, navigation, and background work

## Content

- **Side by side**, pin, and maximize keep two related sessions visible
- `Ctrl+R` Sessions picker; `Ctrl+Shift+O` jumps **within** the current session
- **Background send** keeps a session working while you move on
- **Restore on reload** keeps in-flight sessions; Close All clears them

## Notes

Once agents run across several windows the bottleneck is you. This topic is the hands-on core of the module and builds the lab.
