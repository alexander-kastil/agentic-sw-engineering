# Agentic DevOps

## Testing, Documentation, Azure DevOps & Infrastructure

Integrate AI-assisted development with enterprise DevOps practices. This module opens with agent-generated tests and documentation as the quality foundation, then moves to Azure CLI automation, infrastructure as code, and CI/CD pipelines so shipped work stays measurable and verifiable.

| Topic                                                             | Description                                                                                      |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |

| **[Documentation using Copilot](./02-documentation/)**            | Produce docs with Mermaid diagrams rendered in Markdown preview, notebooks, and chat.            |
| **[Automation using Azure CLI](./03-azure-cli/)**                 | Translate scripts and automate Azure operations using Azure CLI with AI-assisted development.    |
| **[Infrastructure as Code (IaC) - Bicep & Terraform](./04-IaC/)** | Define infrastructure as code using Bicep, Terraform, and azd with Copilot coding agent support. |
| **[Azure DevOps Pipelines & GitHub Actions](./05-pipelines/)**    | Build CI/CD pipelines with Azure DevOps and GitHub Actions for automated testing and deployment. |
