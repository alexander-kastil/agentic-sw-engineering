# Ask the codebase

## Content

- Ask where a request enters, how auth is enforced, which module owns the logic
- The answer cites **files and lines**: follow them before you trust it
- Ask for an architecture overview or a "start here" guide for one subsystem
- `/share` saves the session; `copilot init` writes an `AGENTS.md` for the next question

## Notes

A multi-day onboarding becomes a conversation, but only as good as the citations you check.
