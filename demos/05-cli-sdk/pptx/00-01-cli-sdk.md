# GitHub Copilot CLI & SDK

## Content

- **CLI**: the agent in your terminal, interactive or headless with `copilot -p`
- **Agentic Workflows**: a prompt that runs on a schedule with `gh aw`
- **SDK**: the same runtime inside your own applications, in six stacks

## Notes

Two surfaces, one runtime. Everything the class learned about the harness in the editor carries over; what changes is who is at the keyboard.
