# Fundamentals & Agent Mode Basics

## GitHub Copilot Essentials

Master the core capabilities and foundational concepts of GitHub Copilot, from inline code suggestions and chat interactions to advanced prompting techniques, context engineering, and multi-model selection. This module then pivots early to Agent Mode, so you leave the fundamentals already driving a local agent through real, multi-step work.

| **[AI-Assisted Coding Essentials](./03-ai-assisted-coding/)** | Prompting techniques, inline suggestions, slash commands, and context variables together in one place.                 |
| **[Agent Mode Basics](./04-agent-mode-basics/)**          | Use local agents in Agent Mode for real-time, multi-step assistance: scaffold a project, fix an error, and run an update. |

| **[Configuring & Governing Copilot](./06-mgmt-settings/)**         | Configure Copilot policies at organization, repository, or user level to control features and set governance guardrails.  |
| **[Working in the Terminal](./07-terminal/)**              | Understand machine-readable agent output via the VSCODE_AGENT variable and terminal output compression for test runners, builds, and linters. |
