# Annotating a page for the agent

## Content

- Select an element with **`Ctrl+Alt+C`** (`Option+Cmd+C` on macOS) and comment on it
- The agent gets **the element and your note** together
- `workbench.browser.autoReloadOnFileChange` reloads local HTML on every edit
- Edit and rendered result stay in step without a manual refresh

## Notes

Describing a visual defect in words is the slow half of the loop. Available since VS Code 1.132 and 1.133.
