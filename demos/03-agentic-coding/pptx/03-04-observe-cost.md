# Observe and account for delegated work

## Content

- Open a subagent's transcript as a **read-only peer chat**: follow it, never steer it
- Agents window shows **model, elapsed time, current tool call** per subagent
- Activity pills: live counts for **Changes, Previews, Subagents, Browsers**
- Each subagent shows its **own credit cost** on hover; pin an exact model ID

## Notes

Model choice and delegation depth are budget decisions; this ties into the Governance cost module.
