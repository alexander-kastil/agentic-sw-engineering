# Implementing agentic coding

## Content

- Five ways to put an agent to work: **local**, **cloud**, **orchestrated**, **browser-verified**, **modernization**
- Start small in Agent Mode, then scale out
- Leave able to pick the right delegation model for the job

## Notes

The module climbs from the simplest delegation to the most ambitious. Each topic is a different way to get real work done; the next module covers the session infrastructure underneath.
