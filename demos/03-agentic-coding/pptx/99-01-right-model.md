# Pick the right way to delegate

## Content

- **Bounded and interactive**: Agent Mode
- **Well-scoped and long**: cloud agent with `/delegate`
- **Spans domains**: orchestrator with expert subagents
- **Web change** or **migration**: let the agent verify and research
