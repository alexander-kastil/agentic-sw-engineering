# Agentic browser automation

## Content

- Open and navigate, **read the console**, **screenshot into chat**, click and type
- **Device emulation** through generated Playwright code you can keep as a test
- Favorites, history, and a remote proxy for corporate networks
- Governed by the **`BrowserChatTools`** policy

## Notes

GA and on by default since VS Code 1.127. The agent that writes the code now verifies it in a real browser.
