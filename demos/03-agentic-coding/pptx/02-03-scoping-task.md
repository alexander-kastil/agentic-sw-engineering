# Scoping a task worth delegating

## Content

- Nobody is there to answer a mid-run question
- A good brief: **problem**, **acceptance criteria**, **which files change**
- Fits: test coverage, reproducible bugs, config and docs, mechanical refactors
- Keep exploratory or turn-by-turn work local

## Notes

Short tasks lose to container startup overhead. Delegate the well-defined, keep the judgement calls.
