# Implementing Agentic Coding

## Putting Agents to Work

The fastest way to learn agents is to put them to work. This module builds up from the simplest delegation to the most ambitious: run an agent locally in Agent Mode, hand a heavy job to the cloud, coordinate several specialists at once, let an agent verify its own web changes, and close with an agent-led modernization. Each topic is a different way to get real work done, so you leave able to pick the right one for the job.

You start small and local with Agent Mode, then scale to cloud delegation and multi-agent orchestration, and finish with browser automation and a framework migration. The session mechanics that run underneath all of this, the Agents window, persistence, subagents, research, and troubleshooting, are covered in the previous module, Agent Sessions.

| Topic | Description |
|-------|-------------|
| [Using Local Agents and Agent Mode](./01-local-agents/) | Run an agent on your own machine in Agent Mode, the baseline every other delegation model is measured against. |
| [Delegating Tasks to Cloud Agents](./02-cloud/) | Hand large-scale tasks to a remote Azure environment that exceeds local resources. |
| [Multi-Agent Orchestration](./03-orchestration/) | Coordinate specialized agents for multi-step workflows with parallel execution. |
| [Agentic Browser Automation](./04-browser-tools/) | Built-in browser tools that let agents open pages, read console errors, and verify their own web changes. |
| [Upgrading & Modernization](./05-upgrading/) | Agent-led framework migration, such as Semantic Kernel to the Microsoft Agent Framework. |
