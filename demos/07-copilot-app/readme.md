# GitHub Copilot App

## Agents Outside the Editor

The GitHub Copilot app is a desktop agents view for macOS, Windows, and Linux that works on any Copilot plan or with a bring-your-own-key endpoint. It shows what agentic development looks like beyond VS Code: start a session from a GitHub issue, a freeform prompt, or an in-flight pull request, each running in its own isolated worktree. A built-in validation loop lets you review diffs, drive an in-app browser and terminal, and merge the pull request without leaving the session. Repository MCP servers and skills sync automatically, and scheduled automations turn them into recurring work.
