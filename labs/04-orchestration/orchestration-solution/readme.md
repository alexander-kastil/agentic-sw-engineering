# Delegation Test

This page converts temperatures between Celsius and Fahrenheit. Type a number in either field and the other field updates automatically. Converted values display with one decimal place, so 0 C reads as `32.0`.

This folder is the reference solution for [the lab](../readme.md). Your own run of the lab prompt writes the same five files to `src/scratch/delegation-test/`; compare them against this copy.

## How to open

Double-click `index.html`, or from the repo root run:

```powershell
start labs/04-orchestration/orchestration-solution/index.html
```

To open your own run instead:

```powershell
start src/scratch/delegation-test/index.html
```
