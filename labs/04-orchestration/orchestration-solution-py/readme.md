# Delegation Test (Python)

This page converts temperatures between Celsius and Fahrenheit. Type a number in either field and press the Convert button under it; the page reloads with the other field filled in. Converted values display with one decimal place, so 0 C reads as `32.0`.

This folder is the reference solution for [the Python lab](../readme-py.md). Your own run of the lab prompt writes the same five files to `src/scratch/delegation-test-py/`; compare them against this copy.

## How to run

Python 3.10 or later, standard library only. From the repo root:

```powershell
python labs/04-orchestration/orchestration-solution-py/app.py
```

Open <http://127.0.0.1:8000/> and press `Ctrl+C` in the terminal to stop the server.

To run your own build instead:

```powershell
python src/scratch/delegation-test-py/app.py
```
